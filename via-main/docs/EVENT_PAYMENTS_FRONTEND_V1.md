# Etkinlik Ödeme Planı ve Tahsilat Frontend v1

## Amaç

Etkinlik detay ekranında anlaşma bedelinin ödeme planı ve tahsilatlarını takip etmek.

## Eklenenler

- Etkinlik detay paneline `Ödeme Planı ve Tahsilatlar` bölümü eklendi.
- Ödeme planı satırı oluşturma eklendi.
- Tahsilat kaydı oluşturma eklendi.
- Tahsilatı yapan ortak seçimi eklendi.
- Tahsilatı ödeme planına bağlama eklendi.
- Tahsilat iptal işlemi eklendi.
- Özet kartları eklendi:
  - Anlaşma Toplamı
  - Planlanan
  - Tahsil Edilen
  - Kalan

## V1 sınırı

- Ödeme planı düzenleme UI henüz eklenmedi.
- Kasa/banka/ortak hesap hareketine otomatik transfer bu adımda yok.
- Tahsilat iptal edilir, fiziksel silinmez.
