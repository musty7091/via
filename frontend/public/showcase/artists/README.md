# VIA EVENTS Public Showcase Medya Klasörü

Bu klasör halka açık sanatçı vitrini için ayrılmıştır.

Her sanatçı için önerilen yapı:

```text
grup-frekans/
  cover.jpg
  hover.mp4
```

Kurallar:
- `cover.jpg`: kartta görünen siyah-beyaz veya siyah-beyaza yakın kapak görseli.
- `hover.mp4`: mouse kartın üstüne gelince oynayan sessiz kısa performans videosu.
- Video önerisi: 5-8 saniye, MP4/H.264, ses kapalı, 640x800 veya 720x900.
- Dosya ve klasör adlarında Türkçe karakter, boşluk ve parantez kullanmayın.
