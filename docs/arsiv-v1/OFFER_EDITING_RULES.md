# Teklif Düzenleme v1

## Amaç

Taslak teklif oluşturulduktan sonra kullanıcı, teklif bilgilerini arayüzden güncelleyebilmelidir.

## Düzenlenebilen alanlar

- Müşteri
- Mekân
- Program paketi
- Teklif başlığı
- Etkinlik tarihi
- Teklif geçerlilik tarihi
- Fatura tipi
- KDV oranı
- Ana para birimi
- Ön ödeme
- Ödeme şartları
- Müşteriye görünecek not
- İç not

## Paket değişikliği

Taslak teklifte program paketi değişirse teklif satırları yeni pakete göre yeniden oluşturulur.

Kombine paketlerde teklif toplamı paket satış fiyatından hesaplanır. Paket içeriği müşteriye program akışı olarak gider, aynı kalemler ikinci kez teklif toplamına eklenmez.

## Anlaşmaya çevrilmiş teklifler

Anlaşmaya çevrilmiş teklifler serbest düzenlenmez. Çünkü bu noktadan sonra etkinlik dosyası, ödeme, gider ve kârlılık takibi oluşur.

İleride bu ihtiyaç için Revizyon / Ek Protokol mantığı kurulacaktır.
