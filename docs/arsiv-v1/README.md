# Arşiv: v1 iş kuralı dokümanları

Bu klasör, Haziran 2026'da bırakılan ilk sürümün iş kuralı dokümanlarıdır. Kod artık
`apps/` altındaki v2'dir; bu dokümanlar fikir kaynağı olarak saklanır.

Çelişki durumunda geçerli olanlar sırasıyla:
1. [Sahibin onayladığı kararlar](../PROJE_RONTGENI_2026_10.md#8-sahibin-onayladığı-kararlar-5-ekim-2026)
2. v2 kodu ve testleri (`apps/api/tests`)
3. Bu arşiv

Örnek farklar: kâr her zaman eşit 1/3 bölünür (yüzde yönetimi yok); kâr tahsilat ve etkinlik
kapanışıyla dağıtılır; zarar da ortaklara bölünür.
